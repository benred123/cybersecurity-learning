# Linux Fundamentals

This section records Linux commands and concepts I practise in authorised training environments.

## Topics to learn
- Files and directories: `pwd`, `ls`, `cd`
- Reading files: `cat`, `less`, `head`, `tail`
- Finding files and text: `find`, `grep`
- Permissions: `ls -l`, `chmod`, users and groups
- Processes and services: `ps`, `top`, `systemctl`

## First practice exercise
In a local Linux terminal, run `pwd`, `ls -la`, and `whoami`. Record what each command shows in your own words.

> Learning checklist, not a claim of mastery. Add dated examples after practising.
