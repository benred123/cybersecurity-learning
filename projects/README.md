# Cybersecurity Projects

This folder will contain completed, reproducible projects and lab write-ups.

## Project standards
1. State the objective and authorised environment.
2. Describe the tools and methodology in your own words.
3. Record evidence with sensitive details removed.
4. Explain findings, mitigations and lessons learned.
5. Respect lab-platform write-up and spoiler rules.

Use [the project template](PROJECT-TEMPLATE.md) for new work.

## Planned projects
- Linux command-line investigation
- Network traffic analysis in a local lab
- Introductory web security exercise
