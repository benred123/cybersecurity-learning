# Networking Fundamentals

## Learning checklist
- IP addresses, subnets, private vs public addressing
- TCP vs UDP and common ports
- DNS, DHCP, HTTP and HTTPS
- OSI and TCP/IP models
- Basic troubleshooting with `ping`, `ip addr`, `ss`, and `traceroute`

## Practical exercise
Inspect the network interfaces on your own computer or lab VM. Record the private IP address (redact sensitive information before publishing), default gateway concept, and what you learned.
